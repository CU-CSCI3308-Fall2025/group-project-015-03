# Tumble Stack

Tumble Stack is a social journaling web application built for college students. Users can create customized profiles, write entries based on daily prompts, and explore content from others. Our goal is to make reflective writing more engaging, personal, and community-driven.ling application for college students in which users can create and customize their own profiles. Users can pick a specific topic or choose from the three prompts of the day and journal based on the given prompt.

## How to run our app

1. Clone the repository:
   git clone https://github.com/CU-CSCI3308-Fall2025/group-project-015-03.git

2. Navigate into the project directory:
   cd group-project-015-03/ProjectSourceCode

3. Make sure Docker Desktop is running.

4. Build and start all services:
   docker compose up --build

5. Once the build finishes, open the app in your browser:
   http://localhost:3000


## How to test our app

1. Make sure you are inside ProjectSourceCode:
   cd ProjectSourceCode

2. Install dependencies:
   npm install

3. Run all tests:
   npm test
